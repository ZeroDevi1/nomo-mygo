# LaTeX / Typst 编译预览

打开可信的 LaTeX 或 Typst 稿件后，从稿件工具栏的视图菜单选择**语义编辑**、**仅源码**、**仅 PDF**或**源码 + PDF**。

- **语义编辑**提供单栏写作画布。标题、强调、Typst 项目符号和常见公式可直接阅读。点进所在行或公式块即可编辑原文，展开的源码和仍可见的原生命令沿用源码编辑器的语法高亮。移开光标后恢复渲染。输入法预编辑留在画布中，提交后作为一步写入源码缓冲。切换到源码视图可继续使用同一份未保存内容和撤销历史。
- **复杂块**由 Typst 或 XeLaTeX 局部排版。LaTeX 支持带标签的公式与多行对齐、定理与证明、列表、浮动图表和常见表格环境，沿用导言区的宏、宏包和模板。Typst 支持带标签的公式、`#figure`、`#table`、`#thm`、`#proof` 等，沿用块前的 `#import`、`#let`、`#set` 和 `#show`。图表可引用稿件目录内的图像和数据。点击预览会在同处展开整个块的源码，包括图题、标签和表格内容。
- **局部排版范围**包括闭合的公式、图表、代码块和导言区声明的常见 LaTeX 块命令，也覆盖引用项目自定义宏的行内公式。带标签的常见图、表和独立公式使用当前稿件版本的正式编号。编号尚未就绪时，局部预览隐藏编号或显示省略号。Typst 可读回普通引用以及仅在引用前后添加文字的简单包装命令。任意宏、复杂多行编号和分页以整稿 PDF 为准。依赖局部上下文以外资源、未闭合或超预算的块可直接编辑原文。语义画布适用上限为 4 MiB 和 32000 行。
- **实时编译与导出**读取未保存稿件。画布局部排版只处理可见片段；停笔 1.5 秒后，Typst 用支持文档查询的 `typst eval --in` 更新编号，不生成 PDF；LaTeX 复用整稿编译的辅助文件，无需将 PDF 转为页图。过时结果不会回填。切换到 PDF 可查看正式排版。项目导出从主文件编译，叠加当前窗口未保存的章节和书目，成功后才替换目标文件。切回仅源码会释放预览会话。

语义画布上方有**文字、段落、页面、插入**四组控件。选中文字可改字体、字号、颜色、底色和上下标。段落面板可设置行距、段间距、首行缩进、对齐和背景，也能转换标题级别。页面面板可设置纸张、方向、页边距、分栏、页码、页眉页脚和正文默认样式。页面属性的实际分页效果在 PDF 中查看。LaTeX 的页面设置写入主稿导言区。

**插入 → 公式**提供行内、独立和编号公式，并有分式、根式、上下标、积分、求和、极限、矩阵和分段函数的参数表单。把光标放到受支持的已有公式中，可再次打开表单。**插入 → 交叉引用**按标题、编号和标签搜索，可按章节、公式、图、表筛选。编译尚未完成时，仍可从当前文件的标签中选择。

点击画布中的图表卡片可打开编辑面板，查看图片或表格预览，修改支持的宽度和题注。把图片或 CSV 拖到画布可新建图表，也可拖到插图卡片替换图片。项目外的图片在应用时复制到 `assets/`。新拖入的 CSV 会预览并转为原生表格，最多 30 行、12 列。已有的外部 CSV 和通过 `\input` 引入的常见 LaTeX 表格仍可打开数据源。查看图表的原有代码可用**查看源码**。

LaTeX 的 `\maketitle`、`thebibliography` 和 Typst 的 `#bibliography` 支持局部预览。Typst 参考文献预览会列出书目中的全部条目，正式输出仍按原稿的书目规则。通过 `\lstinputlisting` 或 Typst 的 `#raw(read(...), block: true)` 引用的代码可预览及打开源文件。文档设置会读回常见模板字段，例如四边页距、正文尺寸和行距。通过**补充文档样式**可以添加背景等设置。样式修改可与正文一起撤销。

**插入 → 自定义命令**可填写 LaTeX 命令或环境、Typst 函数或 `set` / `show` 规则。面板列出当前文件识别到的部分自定义命令。复杂模板、自定义宏和手动改写的复杂对象可通过同一面板的**编辑源码**修改。

PDF 视图连续排列纸面，可缩放和上下滚动。拖动分隔条调整双栏比例。文档大纲可按层级浏览 PDF 书签并跳到对应页，也可按源码标题定位。
| 输入 | 完整编译和导出 | 源码与 PDF 双栏的实时段落试排 |
|---|---|---|
| LaTeX | XeLaTeX，按需调用 BibTeX 或 Biber | 随应用内置的 Typst |
| Typst | 随应用内置的 Typst | 合并输入后由 Typst 编译整页 |

发行包内置 Typst、PDFium 和 Noto Sans SC 常规字体。PDFium 负责分页、页图和 PDF 文字提取，无需安装 Poppler。Typst 使用系统、项目和随包字体。来自 Typst Universe 的项目依赖首次获取时可能需要联网，之后使用 Typst 的缓存。未打包的开发运行可使用本机 Typst 和 Poppler。

首次预览、局部排版或导出 LaTeX 时，发行版 Nomo 下载便携 TeX Live、SyncTeX 和 CTeX 字体及宏包。未打包的开发运行可以使用本机 TeX Live。Windows x64、macOS 和 Linux x64 的首次下载约 166–257 MiB，安装到 Nomo 的用户缓存。下载过程中仍可编辑源码，关闭预览可取消该预览的下载，之后可通过重新排版重试。准备完成后，已包含宏包和字体的项目可以离线编译。使用自定义字体和模板的项目仍需提供指定资源。中文模板可使用 `fontset=fandol`，避免依赖操作系统自带的字体名。当前便携包的 arm64 Biber 要求 macOS 26 或更新版本。较早版本的 Apple Silicon Mac 可编译不依赖 Biber 的稿件（包括传统 BibTeX）。

LaTeX 实时模式用 PDF 文字坐标定位上一份 PDF 中的段落。若变更只涉及一个段落，且能找到唯一匹配，就在右侧切到对应页，在原矩形内更新文字。纯正文直接使用原页的字号、行高和缩进试排。支持的粗体、强调和行内公式用 Typst 试排。输入期间不挤动周边内容，超出原框的正文可能暂时裁切。停顿后 XeLaTeX 重新排整页，若能重新定位则跟随新页码。重复段落、跨页段落或缺少文本层时，使用试排卡片或等待整页。每次成功编译替换上一份索引，最多保留 8192 个段落。

点击 PDF 正文可定位到源码行，在纯预览中点击会展开双栏。LaTeX 优先使用 SyncTeX，Typst 按点击的词和相邻文本匹配源码。空白区域、无法区分的重复行或过期页面不跳转。

源码编辑器提供本地高亮、括号配对和补全。在 LaTeX 中输入 `\`、在 Typst 中输入 `#` 即可查看命令、签名和所选命令的简要说明。继续输入 `\subsec`、`\begin{equa`、`#fig` 或 `#set tex` 可看到候选名称与签名；按 Enter 接受，也可在命令或环境名位置按 Ctrl+Space 手动触发。LaTeX 导言区的常用宏声明、Typst 的 `#let` 名称也会参与提示（当前文件前 32 KiB，最多 128 个声明）。没有启动语言服务器或扫描工作区。

XeLaTeX 禁用 shell escape，使用独立辅助目录；检测到文献库时运行相应后端，再按日志补跑，总计最多三遍 XeLaTeX。依赖外部脚本的项目仍应使用项目原有构建流程。

## 从 Go 调用

`nomo/desktop/typeset` 不导入 UI 框架，接受内存中的源码，返回标准库的 `image.Image`。以下代码在仓库的 Go 模块中运行，`path` 是主文件路径，`source` 是当前缓冲内容：

```go
session, err := typeset.Open(path)
if err != nil { return err }
defer session.Close()

pages, err := session.Compile(ctx, strings.NewReader(source))
if err != nil { return err }
page, err := session.Page(ctx, pages) // 页码从 1 开始；这里读取末页
if err != nil { return err }
// page 可交给 png.Encode 或交由原生界面绘制。
_ = page

return typeset.ExportPDF(ctx, path, strings.NewReader(source), destination)
```

每个预览窗口由单个工作协程串行使用会话，后台标签没有常驻编译器。UI 只投递最新的只读源码快照，新编辑会取消过期整页任务，关闭预览会结束子进程并清理临时文件。预览保留最近一次成功的 PDF（上限 128 MiB），先以 1400 像素长边显示首张页图，再按可见纸面的实际设备像素从 PDF 补绘。页图缓存按同屏页数分配 128 MiB 的 RGBA 像素预算，超出预算的显示尺寸以受限分辨率呈现。重编译成功后替换缓存，关闭预览后释放。段落缓存只保留一张、最多 1200 × 640 像素。独立导出不复用试排图片。

语义画布的复杂块只在可见时提交局部排版，复用窗口现有位图缓存。同一上下文每批至多 6 个片段共用一次编译；失败批次可拆开，避免一处错误遮住其他块。独立串行队列最多排队 32 块，满时可见请求会等空位。每块最多 96 行、16 KiB，声明上限 64 KiB。离开画布或更换样式版本会取消旧请求。缓存预算计入块源码、声明和解码后的位图。项目编号索引最多保留 2048 项，随排版会话释放；打开表单时才加载外部数据或代码预览。

## 连续输入回归

`TestThesisContinuousPreview` 从 `NOMO_THESIS_PREVIEW` 指定的目录读取 `math-talk.tex` 和 `figures/`，编辑临时副本。使用 1200 × 800 的 MyGo 无头窗口，每 60 ms 向编辑器输入一个中文字符；每轮 24 字，共三轮，每轮都等 XeLaTeX 校正后再继续。测试测量输入事件到试排帧的时间，检查页码、页面与锚框的坐标，并将本轮末次试排截图与本轮初始页面逐像素对比（排除锚框与两像素边缘）。正式重排允许后续内容移动。

本机 Apple M4、macOS、TeX Live 2026 的 36 页讲稿测试：72 次输入全部在输入期间出现对应更新；首帧约 35 ms，预热后 71 帧 P50 16.7 ms、P95 19.9 ms。三轮末次按键到试排帧为 16.5、15.5、17.7 ms。同轮内无跳页、锚框无位移，抽查的框外像素无变化。这些数字是首页普通中文段落的编辑器帧延迟，不包括显示器扫描、输入法组词或整篇 XeLaTeX 编译。

```sh
NOMO_THESIS_PREVIEW=/path/to/Thesis go test ./desktop/ui/shell -run '^TestThesisContinuousPreview$' -count=1 -v
```

## Finder 快速查看

安装带 Quick Look 扩展的 macOS 构建后，选中 `.tex` 或 `.typ` 并按空格，可连续滚动、选择和缩放 PDF。首次使用时，在 Nomo 中预览或导出**已保存**的主文件即可生成快照。Finder 按主文件的路径和内容摘要读取最近一次成功排版，并标注构建日期。只改动章节、图片或字体时，请在 Nomo 中重新编译以更新快照。

扩展也会尝试读取有权限访问且不早于主文件的同名 PDF。两者均不可用时直接显示源码开头（最多 256 KiB）。Quick Look 沙盒内不启动外部编译器，翻页复用同一份 PDF。快照存放在用户缓存目录的 `com.nomo.desktop/QuickLookPDF`，对不超过 16 MiB 的主文件生成，最多 12 份、合计 128 MiB，按最早编译时间淘汰。Markdown 沿用原生富文本预览。
