# Nomo Scholar 阅读与写作界面打磨计划

先让读者在参考文献 PDF 中框选文字或图表，带着选区向 Codex 提问，再从对话回到原文核对。随后补齐返回稿件的路径，调整右栏和状态入口，让详情、批注、对话、审阅与诊断按当前任务出现。

现有工作区已提供 PDF 区域选取、发送前引用预览、Zotero 批注跳页、窄窗返回稿件以及逐处审阅。首轮复用这些入口，沿用 Zotero 三栏和稿件的源码／PDF 布局。全文解析、翻译、外部检索工具和多 Agent 配置留待单独规划。[Nomo Scholar 使用说明](nomo-scholar.md) · [ACP 开发计划](scholar-acp-plan.md)

## P0 从 PDF 选区直接提问

1. 在现有选区工具条把「问这段」放在首位。框选文字后一次点击即可附上引文并聚焦 Codex 输入框。同一文献有最近会话时继续该会话，否则准备新草稿。输入框显示将要发送的选区，用户主动发送。保留「新开对话」「复制文字」「改用截图」入口。
2. 截图模式使用「问这张图」。文字提取为空时保留框选，并提示切换截图。适配器未声明图片输入能力时，在选区处说明原因。提取失败、取消或切离文献时保留原有草稿，过期提取结果直接丢弃。目标会话与当前未发送草稿所属会话不同时，提供「加入当前草稿」和「切换会话」两个明确入口。
3. 浮层沿用现有选区坐标，靠窗口边缘时移到空余一侧。明确区分「文字」「截图」，为图标和快捷键提供焦点提示。窄窗仍可访问次级动作，`Esc` 收起浮层并返回阅读区。

实现入口为 [PDF 与网页引用](../desktop/ui/shell/scholar_acp_reader.go)、[Codex 会话与输入框](../desktop/ui/shell/scholar_acp.go)。[Agentero 伴读截图](https://docs.agentero.app/assets/agent.png) · [Agentero 选区交互](https://github.com/poco-ai/Agentero/blob/7f59742/docs/frontend/agent.md)

## P0 从对话回到同一页原文

1. 使用统一的引用标签，例如 `Wang 2025 · p.6 · 截图`。发送前可预览和移除，发送后在对应用户消息下显示「已附材料」。随提示为每份材料附上引用 ID，并请 Codex 在使用时标明该 ID。只将能匹配到本会话已发送材料的标记渲染成「引用出处」，其余内容按普通文本显示。把引用绑定到 ACP 会话和消息标识，流式更新和历史回放复用同一关联，旧消息按现有文本方式显示。
2. 引用记录区分书目条目和具体附件。Zotero 来源保留文库与附件键，项目 PDF 使用项目相对路径。定位保存 PDF 物理页序与归一化选区，印刷页码用于显示。点击「查看原文」复用已有阅读标签或打开同一附件。等待目标页就绪后滚入选区并短暂高亮。显式跳转优先于恢复上次阅读位置，连续点击时以最后一次为准。
3. 附件缺失时显示「原文不可用」，并提供已有的重新读取或 Zotero 定位入口。附件内容版本改变或区域失效时，只在同一附件的目标页仍有效时提供页级定位，并标明「选区已失效」。优先用会话回放中的原始引文提供文本预览。回放未带引文时，仍可从标签查看原文位置。

优先检查 [ACP 消息归并](../desktop/internal/scholar/acp_events.go)、[文献标签与跳页](../desktop/ui/shell/scholar_reference_tabs.go) 和 [Zotero 批注跳转](../desktop/ui/shell/scholar_annotations.go)。[Agentero 引用链接](https://github.com/poco-ai/Agentero/blob/7f59742/src/components/agent/context-source-links.tsx) · [显式跳页与阅读位置恢复](https://github.com/poco-ai/Agentero/blob/7f59742/docs/bug_fix/pdf-citation-page-restore-race.md)

## P1 右栏与返回路径

1. 阅读时让「详情」「批注」「对话」共用现有右栏区域，页头显示当前对象，例如 `对话 · Wang 2025`。打开稿件审阅或诊断时复用对应入口。宽窗并排，窄窗单独显示当前面板，保留关闭前的内容位置和用户调整过的栏宽。切换面板时保留已有会话草稿和待审状态。
2. 从稿件进入文献查证时提供明确的返回目标，例如「返回 methods.tex」。复用已有标签和编辑组，恢复稿件光标、分栏比例和编译 PDF 页码。从对话点击来源时同时保留发起跳转的会话位置。若返回目标已关闭或版本失效，使用当前工作区的可用位置，避免重新打开过期缓冲。
3. 保留固定的状态栏和 PDF 页码、缩放入口。窄窗优先保留排版状态、待审和页码，低频操作收进菜单。诊断或待审入口有可靠位置时定位第一项，并使用现有面板展开详情。空白对话只显示与对象相关的动作，例如有 PDF 选区时「解释选区」、在稿件里「检查论证」、有编译诊断时「解释编译错误」。每项先准备可编辑草稿。

实现入口为 [工作区布局与状态栏](../desktop/ui/shell/scholar.go)、[文档工具](../desktop/ui/shell/scholar_toolbar.go)、[编辑组](../desktop/ui/shell/editor_groups.go) 和 [页码控件](../desktop/ui/shell/scholar_page_navigation.go)。[Agentero 布局预设与宽度记忆](https://github.com/poco-ai/Agentero/blob/7f59742/docs/frontend/shell.md)

## 资源与状态边界

- 沿用单个文字选区 16 KiB、单轮文本 48 KiB 和单轮一张 2 MiB PNG 的限制。只在用户触发时提取当前页区域或生成裁片。沿用现有的取消和代次校验，在切页、切标签和关闭窗口时清理过期结果。
- 历史引用只保存用于定位的元数据，复用每项目最近 32 个会话的淘汰范围，引用元数据额外设每项目 128 KiB 的初始预算，超限从最早的记录开始移除。复用适配器恢复的消息文本。截图字节在草稿和发送期间有界持有，历史预览在来源仍有效时按需裁取。定位记录淘汰后，会话正文仍可阅读。
- 跳转、折叠和右栏切换复用现有阅读器及布局状态，返回记录只保留标识和位置。关闭标签时沿用位图和 WebView 的释放路径。选区高亮随定位完成后淡出，切页、关闭或后续跳转时清除。浅色和深色主题复用原有色板，引用类型与状态同时用文字或图标区分。

## 验收顺序

| 阶段 | 操作 | 通过条件 |
| --- | --- | --- |
| P0 选区 | 对有文字层的 PDF 框选一段，对扫描件或表格框选截图 | 一次点击准备草稿并聚焦。选区来源可预览和移除。取消、超限、切页或图片能力不可用时状态可恢复。 |
| P0 回跳 | 发送、追问、切换会话再恢复，从两条消息分别点击出处 | 每条引用对应正确的消息与附件。同名 PDF、多附件、首次打开和已打开且停在别页都定位正确。附件失效时说明情况。 |
| P1 返回 | 从 `methods.tex` 打开参考文献，框选表格提问，再点回原表并返回稿件 | 恢复原光标、编译 PDF 页码和分栏比例，草稿、撤销及待审状态仍可用。宽窗、窄窗和编辑组的返回行为一致。 |
| P1 状态 | 制造可定位的编译错误，再查看多处待审提议 | 状态可区分，入口直接定位对应项。较窄窗口内能看到主要操作，键盘可操作。 |
| P2 文献与界面回归 | 用真实 Zotero 馆藏检索正文、续查、打开附件及子笔记，并向稿件插入引用。用 Codex 验证文字和截图出处，在宽窗和窄窗检查明暗主题及键盘操作。 | 续查保留命中条目，附件可读，引用与书目键一致。出处能回到同一 PDF，随后返回对话和稿件。macOS 上可用空格打开附件的 Quick Look，关闭后可立即继续操作。 |

实施后按改动文件查看现有 LSP 诊断并复核差异。实机验收使用 macOS 和 Windows 的同一组样例，核对浅色、深色、键盘操作和中文输入法。分别记录已验收环境和待验证项。涉及缓存或阅读器生命周期变化时，对照项目性能基准记录适用结果。
