# Nomo Scholar

打开 `.tex`、`.ltx` 或 `.typ` 稿件进入学术工作区。资源管理器目录内的稿件使用该目录作为项目根，其余稿件使用所在目录。首次进入时以当前稿件为主文件，文件树用“主文件”标记对应稿件。项目菜单可打开主文件，或将同项目的当前稿件设为主文件。

## 工作区布局

- **文档工具**提供布局菜单、大纲浮层和检查器开关。大纲可查看标题、公式、图和表，选中项目后定位并收起。新稿件默认使用“源码 + PDF”，同一标签保留布局、分栏比例和 PDF 阅读页。查找、引用和工作区命令从菜单栏或快捷键进入。
- **macOS 导航**在侧栏顶部左对齐显示文件和文献，项目文件树在下方显示。写作助手固定在侧栏底部。侧栏沿用 MyGo 的系统半透明材质。
- **Windows 导航**左侧应用栏的底部是账户与设置。账户页标明本地工作区，设置在主窗口打开。“文件”工作区承载项目树，宽窗口可收起，窄窗口选择文件后返回稿件。界面使用 Fluent 风格的布局和颜色。
- **稿件状态栏**右侧集中显示页码、内容宽度和缩放。点击页码可展开进度条和翻页按钮。内容宽度按同一比例调整源码与 PDF 在各自栏内的显示宽度，当前打开的稿件标签各自记录宽度。切换到参考文献 PDF 标签时，页码显示该文献的阅读位置。
- **PDF 区域**显示编译对应的文件名。暗色主题会调暗画布，纸页默认保留原色。月亮按钮可独立切换当前稿件标签的暗色阅读。
- **检查器与写作助手**分别打开。文献详情和诊断使用检查器。宽窗口下写作助手可和源码、PDF 同时显示，窄窗口由“返回稿件”关闭助手并恢复原布局和页码。临时覆盖稿件时可保留已完成的 PDF，输入未变时直接恢复。

视觉布局参考了 Lattice 的项目导航、源码和 PDF 三区组织。Nomo 将各区的动作放进就近菜单，保留系统窗口控件与键盘入口。[Lattice 中文 README](https://github.com/leo1oel/lattice/blob/main/README.zh-CN.md)

默认主题是 `nomo-ios-blue`，浅色强调色为 `#0088FF`，深色为 `#0091FF`。用户选定的其他主题继续生效。文献、Codex 和 Diff 使用独立语义色。

## 引用与文献

### 项目书目与检索

主文件声明的 BibTeX、BibLaTeX、CSL-JSON 或 Hayagriva YAML 会建立项目索引。LaTeX 支持 `\bibliography{…}` 和 `\addbibresource{…}`，Typst 支持 `#bibliography("refs.yml")` 及字面量路径元组。宏生成的路径仍需改用可解析的声明。

在文献库选择“项目”后，可在工具栏搜索书目、重读项目文献，或从检索选项启用项目 PDF 全文搜索。每行右侧的加号可选中引用，选中后从表格底部统一插入稿件。附件列显示书目中关联的项目 PDF。

在 LaTeX 输入 `\cite{`、`\parencite{` 或 `\autocite{`，或在 Typst 正文输入 `@`，会打开源码附近的检索浮层。可按标题、作者和引用键检索，使用 ↑／↓ 选择、Tab 勾选、Enter 连引、Esc 返回编辑器。Typst 数学、注释及 raw 区域由语法扫描排除。开启 Zotero 结果后，Alt+Enter 可导入当前条目并引用。菜单栏和快捷键也提供独立引用选择器。

引用浮层、文献列表和命令混搜按查询及索引实例缓存结果。磁盘索引查询在后台执行，改变查询会取消旧任务。悬停卡提供元数据、摘要片段、打开 PDF、精读、复制 BibTeX 和 Codex 上下文入口。原格式 BibTeX 的复制路径读取完整索引记录，保留原字段。项目导入保留实际导出记录及已有书目字节，校验重复键、DOI 和文件基准后原子替换。已打开的书目缓冲会阻止磁盘导入。

书目文件元数据每两秒在后台检查，变化后重建索引，打开的未保存缓冲优先。索引驻留预算为 8 MiB，包含首批不可变元数据、按字节淘汰的 LRU 和辅助结构。超出驻留预算时，完整元数据进入会话临时分桶索引，查询与引用校验覆盖全部条目。单个书目文件上限 512 MiB，单条记录上限 1 MiB，临时索引实际写入上限 128 MiB。打开的书目缓冲和一次原子导入有 64 MiB 合计读取预算，超出会明确报错。刷新、取消、关闭和过期发布均有释放路径。

### Zotero 与联网元数据

从侧栏打开“文献”时默认进入 Zotero，可切换到项目书目或联网检索。Nomo 自动探测 Zotero 本地接口，也可点“连接 Zotero”。需在 Zotero 的“设置 → 高级”允许本机其他应用通信。文献库提供个人库、群组库、分类树、标签筛选、最近阅读、未分类条目、个人出版物和回收站。最近阅读记录当前项目会话打开过的附件。未分类条目逐页筛选，空页可继续翻页。

Zotero 本地接口不可用时，文献库会自动只读打开上次成功选择的数据目录。首次使用会尝试用户主目录下的 `Zotero` 文件夹。如果自动读取也失败，可点“打开 Zotero 数据目录…”选择包含 `zotero.sqlite` 的文件夹。工具栏显示“Zotero（只读）”，可分页检索题名、作者、日期、DOI、引用键和摘要，浏览分类、标签、笔记及已下载的 PDF 和批注。PDF 支持 Zotero 的 `storage:` 路径和已保存的绝对路径。以 Zotero 链接附件基目录为基准的 `attachments:` 相对路径暂不解析。馆藏写入、Zotero 全文检索和完整书目导出需要通过菜单中的“连接 Zotero”切回本地接口。

文献区参照 Zotero 的三栏结构：左侧分类与标签、中间条目表、右侧详情。macOS 宽窗复用现有侧栏显示分类；侧栏隐藏时在文献区显示分类栏，空间不足时可切换分类与结果。侧栏图标与文字使用固定槽位对齐，选中背景覆盖整行。文献分类栏使用独立的初始 200 DIP 宽度，不改稿件文件树的宽度。我的文库、最近阅读、分类和特殊视图使用不同颜色的图标；分类搜索只筛选已加载的节点。文献来源（项目、Zotero、联网）通过工具栏左端的下拉菜单切换，工具栏还提供新建、刷新、搜索和检索选项，全文检索开关位于检索选项菜单。Zotero 条目表使用 27 DIP 行高、浅色交替行和整行选择，显示标题、Zotero 返回的创建者摘要及附件状态列；仅已读取的 PDF 附件会显示状态，不用子条目数量推定附件存在。展开箭头取决于实际子条目数量。项目条目仍可按宽度显示年份。分页与当前页数量位于底部。标签云固定在分类栏底部，连接后按页加载，底部输入框提交查询，筛选菜单提供翻页与清除标签；每页最多 25 个标签。

稿件、文献库和文献 PDF 共用一层主标签栏，选中背景覆盖标签整高。文献库与 PDF 标签各有直接关闭按钮。同一项目内切回稿件时保留已打开的文献库标签，显式关闭后移除；关闭当前文献库或最后一个活动 PDF 会返回稿件。PDF 标签关闭按钮与右键菜单复用相同释放路径，取消加载并释放页面位图。

macOS 的 Zotero 分类和标签会留在「文献」侧栏，打开 PDF 或网页标签后仍可使用。从侧栏选择分类、标签或最近阅读时，会显示对应的文献列表，已打开的阅读标签可继续切回。

Zotero 详情采用灰色背景、固定标题和右侧分区图标栏，按信息、摘要、PDF 附件、笔记、文库和分类、标签、相关条目、引用与写作分区，每区可独立折叠，图标可跳转并展开对应分区；折叠状态仅属于当前项目会话。元数据按 Zotero 返回的字段顺序和本地化标签显示，标签右对齐，值左对齐；创建者先显示五位，可展开。子条目需要分页时，附件和笔记数量注明“本页”。窄窗单独显示详情，关闭后恢复列表与检索状态。界面复用原有分页和查询任务，不增加馆藏副本、常驻缓存或后台轮询。当前条目的字段值合计上限 32 KiB、单值 8 KiB、最多 64 字段及 64 位创建者；详情选择失效时随原任务取消。 文献详情、子笔记、批注和编辑表单使用相同的标题（13 DIP）、正文（12 DIP，1.5 倍行高）和紧凑操作（26 DIP）。进入子笔记后，顶部切换到笔记标题与操作，父文献显示为辅助文字，返回使用箭头；分区导航仅显示当前页面存在的分区。新建条目表单最大宽度为 520 DIP，显示期间收起旧详情，取消后恢复。分类名称最多补读 8 个归属，详情最多展示 32 个分类，未解析的名称保留内部键；编辑仍使用完整归属列表。

条目可以展开附件和子笔记。检查器显示条目元数据、子笔记文本、标签及关联条目。无论从文献库还是从 PDF 标签栏的“批注”操作打开，批注页都在固定页头显示附件标题，并提供返回文献详情和刷新操作。点击页码可定位 PDF 页面，已关联到项目书目的文献可从这里插入带页码的引用或引述。条目及标签列表按页加载，子分类展开时才读取。项目导入记录引用键与 Zotero 条目、群组和 DOI 的对应关系。

检查器的“Zotero 操作”菜单提供“在 Zotero 中显示”、复制条目链接和刷新详情，支持个人库、群组库、子笔记与已关联的项目文献。条目链接通过系统协议打开 Zotero，不要求本地接口当前在线。刷新或翻页后，如果当前子笔记已不在结果中，检查器返回父条目。批注列表可刷新当前页，也可直接跳到 Zotero 中的对应批注。

Zotero 10 及以上版本支持在 Nomo 内管理馆藏。在“文献 → Zotero”的工具栏打开新建条目图标菜单（管理 Zotero）可新建文献条目或顶层分类，分类栏顶部也提供新建分类按钮。右键点击分类，可重命名、新建子分类或调整选中条目的归属。选中条目后，在检查器的“Zotero 操作”菜单可编辑该条目类型的元数据、创作者和标签，添加子笔记，或移入回收站。回收站内的条目可恢复。新建和编辑使用相同的表单布局：字段区独立滚动，取消与提交按钮固定在底部。条目字段按信息、创建者和标签分组。

馆藏变更通过 Zotero 本地接口写入，由 Zotero 按既有设置同步。Zotero 会请求写入授权，选择始终允许后，Nomo 可在当前连接内复用授权。编辑提交会校验 Zotero 返回的对象版本，遇到并发修改时可刷新后核对再编辑。

文档、文献库、PDF 和网页标签共用编辑组。右键点击标签可选择分栏方向，或将标签移到已有组。拖动分隔条可调整比例，拖动标签到另一组的标签栏可移动标签；组菜单可合并所有编辑组。每窗口最多四组，布局在本次会话内保留。每个文档沿用原编辑缓冲，分组时稿件组显示编辑视图，合并后恢复稿件布局菜单。PDF 标题只出现在标签上，批注和外部打开位于所属标签栏，窄分组可通过组菜单使用这两项操作。

关闭或移走一组的最后一个标签时，空分栏会自动收起，相邻分栏扩展。只剩一组时恢复单栏和普通标签栏。

在 Zotero 文献列表中，单击条目查看详情，双击条目打开阅读标签。打开时优先读取本地 PDF；没有本地 PDF 时，打开 PDF 链接、条目网址或 DOI 页面。网页在应用内的独立标签中显示，可后退、前进、重载或在默认浏览器中打开。PDF 和网页共用每项目 12 个阅读标签的上限。PDF 依赖本机 Poppler 的 `pdfinfo` 和 `pdftoppm`，单文件上限 128 MiB，只栅格化可见页，单页长边上限 1600 像素。隐藏标签会释放 PDF 位图、取消加载或销毁原生 WebView；网页仅在内存中保存当前地址和至多 128 KiB 的会话快照，阅读位置和历史能否恢复取决于平台。

文献 PDF 和网页阅读标签跟随应用主题。深色模式下，PDF 反转页面亮度并保留部分图表色彩。网页优先采用站点自带的深色样式，仍为浅色的页面会反色，图片和视频尽量保留原色。

没有可读附件或网页地址时，检查器只显示一条可关闭的提示。附件读取失败时，PDF 标签提供在 Zotero 中定位附件、重新读取，以及有网址时打开网页的入口。重试会取消旧加载、重新获取文件路径和页数，并保留原阅读页码；超出新文件页数时定位到末页。

Zotero 全文检索逐批扫描所选库或分类。扫描游标独立于结果分页，后续附件页也会读取。界面显示已扫描条目、总范围、可读 PDF 和无法读取／索引不完整的附件数量。每批最多 25 条元数据，点击“继续扫描”接续位置。结果累计至 200 条时明确提示，继续会替换这一批展示结果并保留扫描位置。缺少附件时仍保留标题、作者等元数据命中。取消或批次超时会保留已完成条目的结果，续查从尚未完成的条目重新读取附件。未索引的附件及响应大小或附件分页上限导致的不可用项单独计数。

离线全文检索同时检查元数据、摘要，以及书目 `file` 字段指向的项目内 PDF。PDF 文本通过本机 `pdftotext` 按需提取，未关联和无法读取的附件单独计数。扫描按每批 25 条续查，展示结果预算为 100 条，替换批次前有明确提示。单个 PDF 上限 128 MiB，提取文本上限 4 MiB，每份 PDF 超时为五秒。未配置附件的书目只能检索元数据和摘要。

DOI、arXiv 编号及论文标题可交给 Crossref／arXiv 检索。用户选择写入目标后才导入。相同 DOI 复用已有引用键，已有键冲突会阻止导入。Zotero 导出优先使用 Better BibTeX，群组及不可用情形走官方导出。批注引用与引述优先使用 Zotero 页码标签（如 `xii`、`S3`），没有标签时使用实际附件页号；LaTeX／Typst 插入会将标签按文本转义。PDF 跳转始终使用实际附件页号，与印刷页码独立。macOS 的附件 Quick Look 按钮可用 Space 激活，经 Zotero 本地文件 URL 接口取得路径后调用系统 `qlmanage -p`，项目取消会结束该进程。

## 本地编辑 Diff

Diff 基于编辑缓冲的前后快照。手动输入合批，撤销、重做与已接受 Codex 修改分别记录。待审提议和已应用记录分开显示，使用 `┆`／`│`、文字与 `+`／`−` 区分。

从状态栏或菜单选择「查看最近改动」，可用上一处／下一处或 Alt+↑／↓ 浏览差异。点击源码行号槽可就地快览。短行复用 MyGo DiffView，长段落使用公开的文本背景 API，按单词、标点和 TeX 控制序列保留字节范围进行差异高亮。每侧 token 模型最多 8192 项，超过部分合并为尾部 token，原文换行与内容保持原样显示。

每个项目窗口保留最多 16 条、192 KiB 的差异片段，单侧片段上限 24 KiB。很长的改动显示截断提示。待处理共享快照使用 64 MiB 逻辑预算，过载时合并连续批次或明确提示较早批次被淘汰。此历史与编辑器 Undo 栈独立。最近一批适合预算的编辑保留前后共享快照，可执行编辑版本 PDF 对照，逻辑预算为 16 MiB。

## Codex 会话与稿件审阅

安装适配器后，Nomo 会在启动时自动连接 Codex 并读取模型选项。已有登录状态会直接复用，需要登录或重试时，聊天侧栏会显示入口。Nomo 从 PATH 查找 `codex-acp`，也可通过环境变量 `NOMO_CODEX_ACP` 指定可执行文件的绝对路径。

```sh
npm install -g @agentclientprotocol/codex-acp@2.6.0
```

侧栏顶部提供会话列表和新开对话，中部显示流式回复和执行详情，底部把输入、附件、模型、推理设置与发送放在同一输入框中。Codex 需要用户确认细节时，侧栏展示可提交、拒绝或取消的表单。输入框左侧的 `+` 或 `⌘/`／`Ctrl+/` 可添加上下文。点击输入框底部的模型按钮可调整思考层级和上下文大小。点击弹层中的模型名称可切换模型。模型、推理选项和斜杠命令来自适配器，菜单也提供 Nomo 自带的写作指令。适配器未提供上下文档位时，GPT-6.1 Sol 和 Terra 可在「自动」「500K」「872K」中选择。手动档位按模型保存，从下次发送生效。Codex 回报实际可用容量后，详情弹层会显示该值。项目偏好保存最近 32 个会话的关联和标识，历史消息由适配器恢复。发起新会话时填写草稿，点击「发送」或按 `⌘Enter`／`Ctrl+Enter` 发送。

- 源码选区可通过拖选、右键、触屏长按或 `⌘K`／`Ctrl+K` 打开贴着选区的工具条。选择「追加会话」会定位到同一稿件或文献最近使用的会话。该来源没有历史会话时会准备新草稿。「新开对话」总是准备新草稿。

## 排版预览与隔离试排

### 常规项目预览

项目主文件也用于子稿件的普通预览和双栏。左侧仍编辑当前章节，PDF 区显示正在编译的主文件名。显式选择主文件、预览同项目子稿件，或检测到其他已打开稿件、已声明书目时，预览进入项目路径。当前窗口的未保存主文件、章节和书目等文本缓冲覆盖对应磁盘文件。无项目联动的独立稿件继续使用现有单文件快速路径。

项目预览在可见期间复用一份私有输入树。编辑合并后仅更新变化的缓冲文件，磁盘变化触发按元数据增量同步，移除覆盖时恢复磁盘内容。旧编译任务可取消，只有当前输入版本能发布结果。输入树沿用 512 MiB、20000 个文件上限，未保存覆盖为 16 MiB。切回源码、切离当前标签或用试排替代普通 PDF 时释放常规预览会话。项目内依赖应使用编译器可从私有树解析的路径。

诊断期间沿用每窗口的一份会话及原有页位图预算，停止段落快览进程。恢复前在编译工作协程核对磁盘输入的文件身份、大小和修改时间，以及编译器记录的外部输入，界面同时核对未保存缓冲的版本。外部输入记录上限为 4096 项和 1 MiB 路径。输入变化或依赖清单不可用时从原页重新编译。BibTeX／Biber 的依赖未包含在 TeX 记录中，使用这两个后端时重新编译。切换标签、项目或离开诊断进入其他面板会释放保留的会话。

在“源码 + PDF”布局中，两栏在停止滚动后跟随到对应段落，点击可立即定位。滚动 PDF 时只移动当前源码的视口，点击 PDF 时可定位到对应的项目章节。LaTeX 使用 SyncTeX 定位，生成的中间文件不会作为跳转目标。仅修改当前 LaTeX 章节且其余输入版本一致时可复用段落快览。Typst 通过排版后的文本匹配源码。遇到重复文本、复杂公式等无法可靠定位的内容时，可能停在附近的可匹配段落或保留位置。项目预览仅匹配该次编译读取的源码。旧版 Typst 仍可生成 PDF。 [Typst 依赖清单格式](https://github.com/typst/typst/blob/main/crates/typst-cli/src/deps.rs)

macOS 的常规项目预览仅在本次编译完全使用磁盘输入、发布前复核输入仍与镜像一致时，才按真实主文件路径更新 Finder Quick Look。Finder 仍读取最近一次成功发布的快照。带未保存覆盖的预览与待审试排均不会写入该缓存。

### 待审与编辑版本试排

试排首先冻结项目输入树，再从同一份冻结树生成编辑前和待审版本。主文件、子文件及当前窗口内其他未保存缓冲一起覆盖到临时树。试排没有真实稿件写回，也不发布正式 PDF 或 Finder Quick Look 缓存。

在源码审阅卡点「PDF 差异」试排当前一处修改；写作助手也可对全部待审修改试排。左栏显示完整源码，未改的行只显示一次，`−` 旧行和 `+` 新行分别用整行底色。接受／拒绝小图标贴在各自片段下方，移到图标上可看提示。跨文件提议可切换左栏文件。右栏在原 PDF 区连续显示修改后的纸面，按文本区铺浅黄底，附近插入带 `−` 标记的浅红旧版裁片。新增页标在页码旁，删除整页由总页数变化反映。两栏独立滚动，可关闭差异标记和裁片，恢复未经插入的纸面。接受或拒绝一处后，对仍待审的修改重新试排。试排失败不会阻止有效文本提议的接受。

有可靠文本锚点时从对应页打开，左栏相应改动也会提供「定位 PDF」。无法定位时从首页开始，并可独立滚动、输入页码，或向前／向后查找差异页。查找每次最多检查 8 页，未找到时停在最后已检查页，可继续查找。比较使用同页号、长边不超过 1200 像素的栅格图，忽略小幅颜色波动。跨页重排会显示为多个页面的差异；不做段落跨页配对，也不比较 PDF 元数据。

每次冻结最多 20000 个文件、512 MiB 输入，未保存缓冲逻辑总量为 16 MiB。快照拒绝符号链接和非常规输入。编译结束释放两份临时输入树，只保留两份 PDF（每份最多 128 MiB）。PDF 虚拟列表按需栅格化可见页，缓存最多 12 页、24 MiB 原始 RGBA，优先淘汰离阅读位置最远的页。旧版整页只在计算差异时短暂使用；每页保留至多 4 段旧版裁片，累计不超过 360 像素高及页高的三分之一。裁片在附近空白处插入，只用于审阅显示。另有差异区域和渲染器缩略层。源码仅为当前查看的文件建立 diff 模型；切换文件时释放旧模型。关闭对照、切离稿件或打开的输入缓冲失效时取消加载并清理临时 PDF。对照以冻结时的输入为准；外部依赖更新后重新试排。

状态栏显示正在排版、最近成功的耗时或失败。排版状态的菜单可取消或重新排版，取消后可从状态栏恢复。点击失败状态打开诊断检查器，可查看最近的日志、定位源文件并返回预览重新排版。空间不足时先收起文献计数和字数，保留排版状态及其操作。编译诊断保留源文件名和行号。XeLaTeX 启用文件行号错误格式，跳转验证项目路径后打开对应源文件。只有 `l.N` 而没有可靠文件名的日志保留原始文本。

### 已查明的框架硬限制

锁定的 MyGo 0.7.4 `ui.InputEvent` 没有公开压力或三指查询事件，无法在应用层可靠区分 Force Touch／三指查询。编辑器 `build.go` 将悬停等待写为 600 ms，`editor.State` 没有延迟配置。250 ms 悬停和上述原生手势需要上游 API 支持。当前提供固定卡、Cmd／Ctrl+Click、F12 及附件 Quick Look 等路径。

该版本的 `editor.State` 公开文本背景、行号槽标记、悬停渲染和实测行偏移，未公开正文行布局插入区。审阅卡根据行偏移和滚动量定位，软换行和折叠下的位置需实机确认。行号槽沿用框架点标记，快览和审阅通过文字和增删符号区分语义。

### 2026-11-11 Windows Zotero 本地库离线读取验证

Zotero 退出后，可以直接从主库读取已落盘的文献和附件。以下是接入前独立运行 SQLite 探测的记录。

- **环境与方法。** Windows 下使用 Python 3.13 自带的 SQLite 3.50.4。测试前后 Zotero 进程数均为 0，开始时本地 API 端口 23119 无监听。以 URI 参数 `mode=ro` 打开 `%USERPROFILE%\Zotero\zotero.sqlite`，设置 `PRAGMA query_only=ON`，在同一读事务内查询。库使用 WAL 模式，`version` 表中 `userdata=131`、`system=32`、`globalSchema=44`、`compatibility=9`。主库和 WAL 的大小及修改时间在测试前后均一致，本次 WAL 为 0 字节。
- **文献与检索。** 在 1 个个人库中读到 83 条未删除的文献、15 个分类、78 个文献标签和 26 条正文非空的笔记。83 条文献有题名，26 条有引用键，21 条有 DOI。题名从 `itemData`、`itemDataValues`、`fieldsCombined` 关联读取，作者从 `itemCreators`、`creators` 关联读取。各取一条实际数据做子串搜索，均命中预期文献。分类归属见 `collectionItems`，标签归属见 `itemTags`，回收站状态见 `deletedItems` 和 `deletedCollections`。
- **PDF 附件。** 从 `itemAttachments` 查得 36 条未删除的 PDF 附件记录。5 条 `storage:<文件名>` 路径解析为 `storage/<附件条目键>/<文件名>` 后可读取，且文件头有效。其余 31 条的路径字段为空。PDF 渲染、链接附件和自定义数据目录尚待验证。
- **运行中的数据库。** 同机 Zotero 运行时，主库的只读查询曾返回 `database is locked`，同目录的 `zotero.sqlite.bak` 可只读查询。接入时可在遇锁后使用已启用的 Local API，或由用户选择有时间戳提示的备份。备份可能落后于主库。读取 WAL 模式的主库时应由 SQLite 协调锁和 WAL，单独复制 `zotero.sqlite` 可能遗漏 WAL 中的提交。本次尚未覆盖非空 WAL。 [Zotero 数据目录](https://www.zotero.org/support/zotero_data) · [SQLite WAL](https://www.sqlite.org/wal.html)
- **Nomo 离线接入。** 每次查询以 `mode=ro` 打开数据库，启用 `query_only`，结束即释放连接。SQLite 用独占锁读取 WAL，索引留在内存，文件层拒绝写入、创建和删除库文件及辅助文件。主库文件句柄需要系统允许获取独占锁，文件被 Zotero 占用时可退出 Zotero 后重试，或连接本地接口。查询可以取消，馆藏按页读取。SQLite 引擎随应用打包，单次查询引擎内存上限为 16 MiB。 [离线连接实现](../desktop/internal/scholar/zotero_disk.go)
